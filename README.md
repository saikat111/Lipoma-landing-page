# সাউথ মুন লাইপোমা রিমুভাল স্প্রে — ল্যান্ডিং পেজ ও অ্যাডমিন ড্যাশবোর্ড
### South Moon Lipoma Removal Spray — High-Converting Bangla Landing Page & Admin Panel

A lightweight, high-converting Bangla medical landing page and Cash-on-Delivery (COD) order management dashboard designed for direct-response e-commerce and Meta (Facebook) Ads marketing in Bangladesh.

---

## 🚀 মূল সুবিধাসমূহ (Key Features)

### 1. ল্যান্ডিং পেজ (Public Landing Page)
- **উন্নত মেডিকেল ডিজাইন**: ক্লিনিক্যাল ব্লু, হারবাল গ্রিন এবং কনভার্সন-ফোকাসড লাল অ্যাকসেন্ট।
- **বাস্তব ছবির ব্যবহার**: আসল বোতল ও প্যাকেটের ছবি এবং কাস্টমার রিভিউ স্ক্রিনশট (মেসেঞ্জার ও ফেসবুক কমেন্টস)।
- **সহজ ৪টি ব্যবহারের নিয়ম**: পরিষ্কার ইনফোগ্রাফিক স্টেপস সহ নির্দেশিকা।
- **ওয়ান-পেজ ক্যাশ অন ডেলিভারি ফর্ম**:
  - প্যাকেজ সিলেক্টর (Buy 2 Get 1 Free কম্বো বা সিঙ্গেল প্যাক)।
  - ডেলিভারি এলাকা সিলেক্টর: **ঢাকার ভিতরে (৳৭০)** এবং **ঢাকার বাহিরে (৳১৩০)**।
  - লাইভ ডাইনামিক টোটাল ক্যালকুলেশন।
  - বাংলাদেশি ১১ ডিজিটের ফোন নাম্বার ভ্যালিডেশন (`01XXXXXXXXX`)।
  - AJAX অর্ডার সাবমিশন ও রিলোড ছাড়া ফাস্ট চেকআউট।
- **মোবাইল স্টিকি বার**: স্মার্টফোন ইউজারদের জন্য কল করুন, WhatsApp ও সরাসরি অর্ডার করুন বাটন।

### 2. ট্র্যাকিং ও মেটা পিক্সেল (Meta Pixel & Marketing)
- বিল্ট-ইন মেটা পিক্সেল ইভেন্টস:
  - `PageView`
  - `ViewContent`
  - `InitiateCheckout`
  - `Purchase` (Thank You পেজে অর্ডার ভ্যালু ও BDT কারেন্সি সহ কনভার্সন ট্র্যাকিং)।
- কাস্টম হেডার ও ফুটার স্ক্রিপ্ট সাপোর্ট (Google Tag Manager, TikTok Pixel ইত্যাদি)।

### 3. অ্যাডমিন ড্যাশবোর্ড (Admin Dashboard)
- **লাইভ মেট্রিক্স**: মোট অর্ডার, পেন্ডিং অর্ডার, আজকের অর্ডার এবং মোট সেলস।
- **অর্ডার ম্যানেজমেন্ট**: ফোন নাম্বার বা নাম দিয়ে সার্চ, ফিল্টার এবং এক ক্লিকে স্ট্যাটাস আপডেট (Pending, Confirmed, Shipped, Delivered, Cancelled)।
- **কুরিয়ার এক্সপোর্ট (CSV)**: স্টিডফাস্ট (Steadfast), পাঠাও (Pathao) এবং রেডএক্স (RedX) কুরিয়ারে বাল্ক আপলোড করার উপযোগী CSV ডাউনলোড।
- **ইনভয়েস প্রিন্ট**: প্রিন্ট-ফ্রেন্ডলি কাস্টমার ইনভয়েস ও প্যাকিং স্লিপ।
- **ওয়েবসাইট সেটিংস**: ড্যাশবোর্ড থেকে প্রোডাক্টের দাম, ডেলিভারি চার্জ, হটলাইন/WhatsApp নাম্বার এবং মেটা পিক্সেল আইডি পরিবর্তন করার সুবিধা।

## 🛠️ প্রযুক্তি (Tech Stack)
- **ব্যাকএন্ড**: PHP (Vanilla OOP, PDO)
- **ডাটাবেস**: 
  - **SQLite** (Default — কোনো কনফিগারেশন ছাড়াই লোকালহোস্ট ও cPanel-এ সরাসরি চলে)
  - **MySQL** (ঐচ্ছিক — `config.php` এবং `schema.sql` দেওয়া আছে)
- **ফ্রন্টএন্ড**: HTML5, Modern CSS (Responsive), Vanilla JavaScript, FontAwesome Icons
- **সার্ভার**: cPanel (Apache) / Local PHP Built-in Server

## 💻 লোকালহোস্টে চালানোর নিয়ম (Localhost Run)
আপনার টার্মিনালে এই কমান্ডটি রান করুন:
```bash
php -S 127.0.0.1:8000
```
এরপর ব্রাউজারে প্রবেশ করুন:
- **ল্যান্ডিং পেজ**: [http://127.0.0.1:8000/](http://127.0.0.1:8000/)
- **অ্যাডমিন ড্যাশবোর্ড**: [http://127.0.0.1:8000/admin/](http://127.0.0.1:8000/admin/)

## 🌐 cPanel হোস্টিংয়ে ডিপ্লয় করার নিয়ম (cPanel Deployment)
1. এই রিপোজিটরির সকল ফাইল জিপ (Zip) করে আপনার cPanel-এর `public_html/` ফোল্ডারে আপলোড করে এক্সট্র্যাক্ট (Extract) করুন।
2. কোনো ডাটাবেস তৈরি করার প্রয়োজন নেই — সাইট ভিজিট করলেই `database/shop.sqlite` স্বয়ংক্রিয়ভাবে তৈরি হয়ে যাবে।
3. ডাটাবেস সুরক্ষার জন্য `.htaccess` ফাইল আগেই কনফিগার করা রয়েছে।
4. আপনি যদি MySQL ব্যবহার করতে চান, তবে cPanel phpMyAdmin-এ `schema.sql` ইম্পোর্ট করুন এবং `config.php`-তে `DB_DRIVER = 'mysql'` দিয়ে ডাটাবেস তথ্য বসিয়ে দিন।
